# Blazing Paddles 2026 — Committee Command Center

Internal dashboard for the Round Rock Fire Foundation's Blazing Paddles pickleball tournament committee.

**Event:** Saturday, October 10, 2026
**Location:** Tejas Pickleball Club, Georgetown, Texas
**Live at:** https://dashboard.roundrockfirefoundation.org

## What's on this page

- Hero overview with date, venue, format, and funding goal
- Live KPI cards (funding, sponsor slots, target list, raffle prizes)
- This Week's Focus action items + Compliance reminders
- Playbook panels: Sponsor Playbook, Sponsor Targets, Raffle Strategy, Outreach Scripts, Planning Timeline, Donation Tracker, Event Operations, Day-of Checklist, Recognition Plan
- Event info quick facts
- Contact CTA

## Tech

Plain HTML/CSS/JS — no build step. Designed to match the public site at
`pickleball.roundrockfirefoundation.org` (same Khand + Satoshi fonts, same flame palette).

```
index.html       — the dashboard page
styles.css       — design system + layout
script.js        — sidebar scroll-spy + footer year
assets/images/   — official 2026 logo and icon
CNAME            — dashboard.roundrockfirefoundation.org
```

## Deploy

This repository is published to GitHub Pages on the `main` branch (root folder).
After pushing changes to `main`, Pages rebuilds automatically in 1–2 minutes.
